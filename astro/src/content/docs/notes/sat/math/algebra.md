This domain focuses on linear equations, inequalities, functions, and systems.

## Recognizing the Question Type

| Question type | What to look for |
| --- | --- |
| Linear equation in one variable | One unknown with a constant rate of change |
| Linear function | A line, slope, intercept, or constant rate in a table, graph, or equation |
| Linear equation in two variables | A relationship between two quantities that can be written in the form $$Ax+By=C$$ |
| System of linear equations | Two linear relationships that must be true at the same time |
| Linear inequality | A range of possible values or words such as *at least*, *at most*, or *no more than* |

:::tip
Identify what the question asks for before calculating: one value, a rate, an intercept, an equation, an intersection, or a range. That target usually reveals the most direct algebraic method.
:::
