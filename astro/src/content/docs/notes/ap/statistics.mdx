AP Statistics is about collecting data carefully, exploring patterns, and using probability to make justified conclusions from samples. These notes now follow the AP Statistics Course and Exam Description effective Fall 2026, which reorganizes the course into five units.

For AP free-response problems, the calculation is usually only part of the answer. You also need to identify the parameter, check conditions, show correct notation, and write conclusions in context.
